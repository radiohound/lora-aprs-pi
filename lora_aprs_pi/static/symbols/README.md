# APRS symbols

`symbols-0.png` (primary table), `symbols-1.png` (alternate table) and `symbols-2.png`
(overlay characters) are the 48 × 48 px renderings (`aprs-symbols-24-N@2x.png`) of the
aprs.fi symbol set by Heikki Hannikainen, OH7LZB: https://github.com/hessu/aprs-symbols

Each sheet is 16 columns by 6 rows; the symbol for character `c` is cell `ord(c) - 33`.
They are offered to APRS applications for free, with a pointer to the source; the
licence of each symbol is listed in that project's COPYRIGHT.md (many CC BY-SA 2.0 or
public domain). They are not covered by this project's MIT licence.
